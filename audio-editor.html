Processing

Edits leave the original file untouched. Preview and export use the clip order above.

WAV / CAF cuts keep the source PCM precision. Effects use 32-bit float, or 64-bit only when the source needs it. Unchanged files in the same format are copied directly. Compressed sources can become larger when decoded to PCM. MP3 / AAC are lossy; AIFF / Apple Lossless convert to 32-bit integer PCM and require confirmation. A lossless export cannot restore quality already lost in the source.
